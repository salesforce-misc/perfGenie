Multiple Progress Bars

            
Run multiple progress bars simultaneously with different IDs. Each progress bar operates independently.

            
            
            
            
            
Click "Start All Progress Bars" to see multiple progress bars running simultaneously

            

                
// Start multiple progress bars with different IDs
ProgressBar.start({ id: 'topBar', position: 'top' });
ProgressBar.start({ id: 'bottomBar', position: 'bottom' });
ProgressBar.start({ id: 'containerBar', container: 'myDivId', position: 'top' });

// Stop specific progress bar by ID
ProgressBar.stop('topBar');

// Stop all progress bars
ProgressBar.stop('topBar');
ProgressBar.stop('bottomBar');
ProgressBar.stop('containerBar');

Progress Bar Inside a Div

            
Place the progress bar inside a specific container div instead of fixed at top/bottom of page.

            

                
This is a demo container div

                
Progress bar will appear inside this div when you click the buttons below.

                
                
            

            
Ready - click buttons to see progress bar inside the div above

            

                
// Option 1: Place inside a specific div (with ID)
ProgressBar.setContainer('myDivId', 'myBarId');  // Container ID, Bar ID
ProgressBar.setPosition('top', 'myBarId');       // Position, Bar ID
ProgressBar.start({ id: 'myBarId' });

// Option 2: Set container and position when starting (one line)
ProgressBar.start({
    id: 'myBarId',        // Unique ID for this progress bar
    container: 'myDivId',  // Div ID string, HTMLElement, or null for fixed position
    position: 'top'       // 'top' or 'bottom'
});

// Option 3: Fixed position (top/bottom of page) - set container to null
ProgressBar.start({
    id: 'topBar',         // Unique ID for this progress bar
    container: null,      // or don't specify container
    position: 'top'       // 'top' or 'bottom'
});

// Make your API call
fetch('/api/endpoint')
    .then(response => response.json())
    .then(data => {
        ProgressBar.stop('myBarId');  // Stop specific progress bar by ID
        // Handle data
    });

            

        


        

            
Animated Icon at Progress Tip 🎨

            
Show an animated icon (emoji or GIF) at the tip of the progress bar that moves with the progress.

            
            
            
            
            
            
            
Click any button above to see the animated icon at the progress tip!

            

                
// Enable default running emoji icon (🏃)
ProgressBar.start({ showIcon: true });

// Use custom emoji icon
ProgressBar.start({ 
    showIcon: true, 
    icon: '⚡'  // Any emoji character
});

// Use custom image/GIF icon
ProgressBar.start({ 
    showIcon: true, 
    icon: { 
        type: 'image', 
        value: 'path/to/running.gif' 
    } 
});

// Icon starting from top
ProgressBar.start({ 
    showIcon: true,
    icon: '🏃',
    iconStartPosition: 'top'  // 'top' or 'bottom' (default: 'bottom')
});

// Icon with splash effect when it touches progress bar (like surfboard hitting water)
ProgressBar.start({ 
    showIcon: true,
    icon: '🏄',  // Surfboard emoji
    iconStartPosition: 'top',
    splash: true  // Show splash effect when icon touches progress bar
});

// Combine with other options
ProgressBar.start({ 
    id: 'myBar',
    position: 'top',
    container: 'myDiv',
    showIcon: true,
    icon: '🚀',  // Rocket emoji
    iconStartPosition: 'top',  // Icon starts from top-left
    splash: true  // Show splash effect when icon touches progress bar
});

Show explosion effects when stopping the progress bar. Choose between crash explosion (fire/smoke/debris) or celebration (colorful sparkles).

Usage Code Example

            

                
// Multiple progress bars on the same page
// Each progress bar needs a unique ID

// Example 1: Progress bar inside a div
ProgressBar.start({
    id: 'apiCall1',        // Unique ID for this progress bar
    container: 'myDivId',  // Your div ID or HTMLElement
    position: 'top'        // 'top' or 'bottom'
});

// Example 2: Fixed position at top/bottom of page with icon
ProgressBar.start({
    id: 'globalProgress',  // Unique ID for this progress bar
    container: null,      // null or omit for fixed position
    position: 'top',      // 'top' or 'bottom'
    showIcon: true,       // Show animated icon at tip
    icon: '⚡'            // Custom emoji icon
});

// Example 3: Progress bar with image/GIF icon
ProgressBar.start({
    id: 'animatedBar',
    showIcon: true,
    icon: {
        type: 'image',
        value: 'https://example.com/running.gif'
    }
});

// Make your API call
fetch('/api/endpoint', {
    method: 'GET',
    headers: {
        'Content-Type': 'application/json'
    }
})
.then(response => response.json())
.then(data => {
    // Stop specific progress bar after API returns
    ProgressBar.stop('apiCall1');
    // Handle response
    console.log(data);
})
.catch(error => {
    // Stop specific progress bar on error
    ProgressBar.stop('apiCall1');
    console.error('Error:', error);
});

// Example 4: Default progress bar (backward compatible, uses 'default' ID)
ProgressBar.start({ position: 'top' });
// Later...
ProgressBar.stop();  // Stops the 'default' progress bar
