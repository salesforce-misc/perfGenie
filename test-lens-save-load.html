Wave Analytics Lens Save/Load Functionality Test

Wave Analytics Component

Test Instructions

This test verifies that lens saving and loading works correctly with multiple filter types in the Wave Analytics component.

Test 1: Basic Lens Save/Load
1. Add some dimensions and metrics to the lens
2. Add metric filters (e.g., CPU > 50)
3. Add dimension filters (e.g., select specific values)
4. Add date/time filters
5. Add search filters
6. Save the lens with a test name
7. Clear the lens (click Clear Lens button)
8. Load the saved lens
9. Verify all filters are restored correctly
Expected: All filter types should be saved and restored exactly as they were
Test 2: Multiple Filter Types
1. Create a lens with ALL filter types:
- Metric filters (multiple)
- Dimension filters (multiple)
- Date/time filters (both relative and absolute)
- Search filters
- Cell/instance filters
- Row filters (ignore some rows)
2. Save the lens
3. Clear everything
4. Load the lens
5. Verify ALL filters are restored
Expected: Complex lens with all filter types should save and load perfectly
Test 3: Filter State Verification
1. After loading a lens, check that:
- Filter drop zones show correct counts
- Filter UI elements show correct values
- Chart data is filtered correctly
- No filters are "stuck" or partially applied
Expected: UI state should match the actual filter state
Test 4: Clear Lens Functionality
1. Create a lens with multiple filters
2. Click "Clear Lens" button
3. Verify that:
- All dimensions/metrics are cleared
- All filter drop zones are empty
- All DOM filter elements are reset
- Chart shows all data (unfiltered)
Expected: Complete reset to initial state
